# 全域使用者與子網站管理列表顯示調整

## 目標

調整兩個後台列表的顯示方式，讓列表只保留必要資訊與明確的編輯入口。

## 設計

### 全域使用者管理

- 移除列表角色欄位的 `RoleSelect` 下拉式即時修改元件。
- 角色欄位改為使用既有 `roleLabel` 純文字顯示。
- 保留列表的「編輯」按鈕；角色仍可在使用者編輯頁依既有流程修改。
- 保留後端 `PATCH /api/admin/users/[id]`，不改變 API、權限與資料模型。
- 刪除不再被列表使用的 `RoleSelect.tsx` 元件。

### 子網站管理

- 從查詢移除 `_count.pages` 與 `_count.posts`。
- 從表頭與每列資料移除「頁面數」及「文章數」。
- 保留名稱、網址代稱、建立時間與操作按鈕。
- 不改變頁面與文章資料、路由或管理功能。

## 驗收條件

1. 全域使用者列表的角色欄位沒有下拉式選單，只顯示角色文字。
2. 使用者編輯頁與角色更新 API 維持現有功能。
3. 子網站管理列表不再顯示頁面數與文章數，也不再查詢這兩個計數。
4. 相關 Vitest 合約測試、TypeScript 檢查與 production build 通過。

## 非目標

- 不修改角色定義、子網站成員固定檢視者規則或資料庫 schema。
- 不修改後端授權與 API 行為。
- 不在本次變更中調整其他後台列表欄位或排序。
